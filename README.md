# Synchronous FIFO Verification

Verification of a parameterized synchronous FIFO using SystemVerilog and Assertion-Based Verification techniques.

## Overview

The project focuses on validating FIFO functionality, protocol compliance, and corner-case behavior through directed and constrained-random testing.

## Features

* Parameterized FIFO Verification
* Assertion-Based Verification (ABV)
* Functional Coverage
* Constrained-Random Testing
* Overflow Detection
* Underflow Detection

## Verification Goals

* Data Integrity
* FIFO Ordering
* Boundary Conditions
* Full and Empty States
* Overflow Handling
* Underflow Handling

## Tools

* SystemVerilog
* ModelSim

## Results

Successfully achieved full functional coverage and validated FIFO behavior across all test scenarios.
